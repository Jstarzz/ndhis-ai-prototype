# Prototype scope

## Included

- Local tool-routing assistant
- Local live speech transcription and translation
- Synthetic hospital-demand forecasting
- Local radiology image interpretation assistance
- Audit metadata
- Runtime model/service visibility
- Rate and concurrency limits
- Tool-routing evaluation
- GPU capacity benchmarking

## Not claimed

- Clinical validation
- Autonomous diagnosis or treatment
- Production NDHIS integration
- Production licensing approval for every prototype model
- Real patient data
- National-scale capacity
- Final medical translation accuracy

The prototype demonstrates architecture, local inference, model specialization, measurable routing behavior, and a path to hardware sizing.
